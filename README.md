## 📋 About

This is a web-based Texas Hold'em poker game built with modern web technologies. Play against the computer and test your poker skills anytime, anywhere!

## 🛠️ Technology Stack

- **Frontend**: React 19 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Runtime**: Bun
- **AI Integration**: Google Gemini AI
- **Animations**: Motion & Canvas Confetti

## 🚀 Getting Started

### Prerequisites
- [Bun](https://bun.sh/) installed on your system

### Installation

1. Clone the repository:
```bash
git clone https://github.com/XYMMM000/Texas-Hold-em-Poker-Mini-Game.git
cd Texas-Hold-em-Poker-Mini-Game
```

2. Install dependencies:
```bash
bun install
```

3. Set up environment variables:
```bash
cp .env.example .env
# Edit .env with your configuration
```

### Development

Start the development server:
```bash
bun run dev
```

The game will be available at `http://localhost:3000`

### Build

Build for production:
```bash
bun run build
```

Preview the production build:
```bash
bun run preview
```

## 📝 Scripts

- `bun run dev` - Start development server
- `bun run build` - Build for production
- `bun run preview` - Preview production build
- `bun run clean` - Clean build artifacts
- `bun run lint` - Type check with TypeScript
